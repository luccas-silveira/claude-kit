# Catálogo

Peças de referência para montar interfaces: blocos de página, estruturas de página inteira,
temas, gêneros e direções estéticas. Copiado do hallmark (`references/`) e do taste-skill; origem
e licenças em [`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

## Pastas

- `components/` — 50 blocos (navegação, hero, seções, CTAs, rodapés). Quando o bloco é montado
  com componentes do shadcn/ui, uma linha logo abaixo do título diz quais.
- `macrostructures/` — 21 estruturas de página; o índice é [`macrostructures.md`](macrostructures.md).
- `themes/` — 5 temas.
- `genres/` — 4 gêneros.
- `direcoes/` — 3 direções estéticas (minimalista, sofisticada, brutalista), do taste-skill.
- Arquivos de apoio que o catálogo linka: [`component-cookbook.md`](component-cookbook.md),
  [`hero-enrichment.md`](hero-enrichment.md), [`assets.md`](assets.md),
  [`custom-craft.md`](custom-craft.md), [`floating-nav.md`](floating-nav.md).
